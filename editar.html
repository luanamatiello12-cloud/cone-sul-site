Páginas do site

Escolha a página.

  1. Abra a página. No canto de baixo aparece a barra com o botão Editar.
  2. Clique em Editar. Aí dá para:
    • clicar em qualquer texto para mudar, inclusive menu, rodapé e botões (Ctrl+B deixa em negrito);
    • clicar num link ou botão para trocar para onde ele leva;
    • clicar numa imagem para trocar;
    • passar o mouse sobre um bloco para subir ou descer, ocultar, apagar, duplicar ou adicionar uma seção nova abaixo (texto, imagem ou vídeo do YouTube).
  3. O que muda no menu e no rodapé vale para o site inteiro.
  4. Clique em Concluir. A mudança fica como rascunho, só para você.
  5. Clique em Publicar para todos verem. Em Histórico dá para voltar a uma versão anterior.
